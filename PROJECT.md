# adba

## Descripción

ADBA - Any DataBase to API. Framework backend oficial del stack: TypeScript + Express + Objection. Convierte cualquier SQL DB (SQLite/MySQL/Postgres/MSSQL) en REST API automática: CRUD completo, paginación, filtros, búsqueda, aliases, hooks, JWT, bcrypt, emails (nodemailer+handlebars+MJML), SSH tunneling, multi-instancia. v1.0.26, ESM+CJS, en npm como adba.
